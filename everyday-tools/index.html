Free tools for the small jobs that fill a day

Use the existing everyday-tools area for a focus timer, calculator, percentage checker, word counter, unit converter, date countdown, bill splitter, temperature converter, random picker and text formatter. The word counter also estimates reading time and counts sentences and paragraphs. Separate launcher apps add a world clock, date and loan calculators, a study score planner, a grocery unit-price comparer, a safe Markdown preview, dice, a colour palette, typing practice, QR creation, pixel art and a local text rewriter.

Resize a picture on your device

For straightforward tasks, choose a picture, fit it inside a maximum width and height, then download a PNG, JPEG or WebP copy. The image-resizer works in your browser and is not a replacement for a full photo editor.

Generate a password locally

Create a long random password with Web Crypto in the browser, choose the character groups and copy the result. It does not store or transmit the password. It is a generator, not a password manager or a place to save credentials.

Calculate, time and organise

Use a calculator for arithmetic, a focus timer for a work interval, or a converter for a quick measurement. Lists and tasks help you keep a reminder nearby rather than trying to turn every tool into a bigger system.

Plan a target score

Enter marks earned so far, the marks available on an upcoming assessment and a target average. The planner calculates the required score using equal point weighting; it does not predict a school grade or account for exam-board boundaries.

Compare pack prices fairly

Compare two products by price per 100 grams, 100 millilitres or item, including different pack sizes such as grams and kilograms. Use the same currency and compare products that are genuinely like for like.

Preview simple Markdown safely

Draft headings, lists, emphasis and code in a live preview. Raw HTML is shown as text, and only ordinary web or email links become clickable; this is a small local preview, not a complete document editor.

Useful free alternatives for simple one-off jobs

A paid productivity, design or document suite can include cloud storage, collaboration, polished templates, automated backups and many advanced features. This hub is not a like-for-like replacement for those services. It offers a set of focused tools for common tasks—such as resizing one image, checking a calculation, timing a session or making a QR code—without asking you to install a desktop editor for that single job.

Some activities are stored with your signed-in account, while others are kept only in the current browser session or on this device. Check the note shown beside a particular tool before entering information. The image resizer and password generator are designed to run locally; the password is not saved, and the image is not uploaded by the resizer. AI chat and external links use separate services and have their own privacy and availability conditions.

  1. Search by the task. Look for “timer”, “image resizer”, “QR code” or another clear purpose in the home-screen app search.
  2. Check the limits. A small browser utility may support a common format or a bounded file size, not every device, document or advanced workflow.
  3. Keep important originals. Download or save a copy where appropriate. A browser tool is not a backup, shared folder or password vault.
No hidden promise of a paid-suite replacement. Use these free utilities for the task they describe, and choose a trusted specialist service when you need collaboration, long-term storage, advanced editing or managed account security.

Everyday tool questions

Are the online tools free to use?

The tools described here are part of the free Everything Hub workspace. A signed-in account is required to open the interactive workspace; third-party links and AI services may have separate terms or limits.

Are files uploaded to use the image resizer?

The resizer processes a selected image in the browser and creates a downloadable copy there. It does not send the image to an image-processing server. Keep your original file until you have checked the result.

Does the password generator save my password?

No. It uses the browser’s cryptographic random-number API and keeps the generated value in the page for you to copy. Do not reuse a password, and use a trusted password manager to store credentials securely.
