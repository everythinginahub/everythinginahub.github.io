Import a timetable file, then review it

The timetable importer accepts a PDF of up to five pages, or a clear JPG, PNG or WebP image up to 12 MB and under 40 megapixels. Text in a PDF is read with PDF.js in the browser; when a page has no useful text layer, it may be rendered and read with local English OCR. It attempts to recognise common weekday grids and simple day-and-time lists, but it can miss or misread subjects, days, times, rooms and teachers.

  1. Choose a clear file. Straight, high-contrast pages are easier to read. Password-protected PDFs, handwriting, unusual rotas and alternating weeks are not supported reliably.
  2. Check every suggestion. Correct the subject, day and start time; add missing details or remove incorrect rows. The scan is a draft, not an authoritative school schedule.
  3. Save only what you confirm. The file and recognised text stay in the browser and are discarded when you leave the import page. Only confirmed lesson details are saved with your account.
Protect private information. The file is processed in the browser by the current importer, not uploaded by that feature. Still, avoid choosing a document that contains personal details you do not need for the timetable.

Student timetable questions

Can I use a timetable for a one-off event?

The planner is designed for lessons that repeat each week. Use a dated task or another calendar for an event that happens once, on a different week or on an alternating rota.

Will timetable import get every lesson right?

No. Text recognition can miss or misread details. Review all proposed entries and compare them with the official timetable before saving.

Do I need an account to save my timetable?

Yes. The timetable is part of the signed-in workspace and its account progress. The static guide is public; opening the interactive planner takes you to the workspace.
